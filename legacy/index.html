复习规则

“还没记住”：10 分钟后再复习，并回到初始阶段。“有点印象”：1 天后复习，阶段保持不变。“记住了”：按 1、3、7、14、30 天逐级延长；达到 30 天后保持 30 天间隔。这是便于理解的轻量规则，不是 SM-2 或 FSRS。只有主动点击自评才改变进度，浏览词卡和查看答案不会计入完成。

实现与扩展

当前采用一个 HTML 文件，内置 CSS、JavaScript 和词库；无需账号、安装依赖或后台服务。进度保存在当前浏览器的 localStorage，发音使用浏览器的语音合成。长期使用建议以固定的本地 HTTP 地址打开；直接双击文件时，浏览器对本地存储的支持可能不同。可导出／导入 JSON 备份；清理浏览器数据、切换浏览器或改变打开地址会影响进度。语音是否离线可用取决于设备语音包。
