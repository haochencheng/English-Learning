# 职场英语学习页面：技术方案

更新日期：2026-11-15

## 1. 目标与学习方式

以 Java 外企求职为主线，将真实职位中的英语转化为「词义理解 → 搭配与跟读 → 主动回忆 → 间隔复习 → 场景输出」。雅思主题练习用于扩展讨论工作、社会和技术的表达；商务英语用于会议、沟通和交付。

当前页面已实现，可直接打开 `index.html`。以单人本地使用为目标，不需要账户、服务器端程序或付费模型接口。

每天建议 20 分钟：5 分钟复习、8 分钟词卡与跟读、7 分钟拼写或场景输出。每日目标是自评 12 个不同词条，包含旧词，不是 12 个新词。已有的《03_外企求职英语三个月计划》继续负责真人课、项目表达和面试模拟；此页面可替换其中的部分自学时间，不必叠加学习负担。

## 2. 已交付功能

| 模块 | 当前行为 |
| --- | --- |
| 今日学习 | 三组词库切换，优先到期复习，再学习新词；也可浏览全部词汇 |
| 词卡 | 英文、词性、中文解释、搭配、原创例句、中文译文、来源链接 |
| 发音 | 朗读单词或例句，优先设备中的英式英语声音，其次其他英语声音 |
| 间隔复习 | 查看答案后选择三种熟悉度，保存下次复习时间 |
| 我的词库 | 按英文、中文、搭配搜索，按类别筛选；点击词条打开词卡 |
| 拼写练习 | 每组 16 题；显示正确答案与例句、统计本轮正确数 |
| 场景表达 | 重复支付、交付延期、科技与工作三个场景；保存各场景的独立草稿 |
| 学习方案 | 学习方法、词库来源、复习规则、实现范围 |
| 数据备份 | 导出 JSON；校验后确认导入，替换当前进度与草稿 |
| 适配 | 桌面和手机布局、键盘操作、减少动态效果偏好 |

拼写允许首尾空格和大小写差异，归一化多余空格与常见连字符；兼容 `prioritise/prioritize`、`root-cause analysis/root cause analysis`。其他题目要求词条的对应词形，例如复数不能随意改为单数。拼写结果不自动修改复习进度，避免把一次拼对当作长期掌握。

场景练习保存提纲并提供参考表达，不录音、不进行 AI 评分。示范答案是原创教学材料，不能直接当成学习者的真实工作经历。

## 3. 词库与来源

当前共 48 个词条，三组各 16 个。所有中文释义、搭配、例句与译文均为本页面编写。

### 求职词库：从已核对的职位正文提取

来源：[LinkedIn 上的 Binance Java 岗位](https://www.linkedin.com/jobs/view/senior-java-engineer-%E2%80%93-fund-security-account-security-fiat-onoff-ramp-at-binance-4488654068/)。该职位覆盖资金安全、法币出入金、账务核对与协作。本次提取词条，未复制完整职位描述。

词条包括 reconciliation、ledger、idempotency、discrepancy 等。专业译义按支付和后端语境选取，避免把普通词义与专业词义混用。保留职位中的复数和短语形式；不宣称已经覆盖全部岗位技能。

### 雅思主题词库：自主选编

以工作、社会、科技话题为范围，选取观点、比较、因果和论证中可用的词汇。它不是雅思官方固定词表，也不将词条标为某个分数段的保证。

练习方法参考 [British Council 的 IELTS 口语词汇运用说明](https://takeielts.britishcouncil.org/prepare/ielts-academic/speaking/tips-lexical-resource?language=en)：关注词语在语境中的准确使用、搭配和释义能力，而不是仅记忆词表。

### 商务词库：自主选编

按会议议程、交付计划、需求澄清、协商和跟进等场景组织，学习方法参考 [British Council 商务英语资源](https://learnenglish.britishcouncil.org/free-resources/business)。这些词条并非逐词摘录自该资源；页面清楚标注为场景补充词汇。

词汇内容为 2026-11-15 的人工精选快照，不自动抓取 LinkedIn，不依赖登录态。职位链接可能随时间更新或下架。

## 4. 当前技术架构

```text
index.html
  ├── CSS：响应式布局、键盘焦点、少量状态动画
  ├── DATA / SOURCES：48 个词条与各类参考链接
  ├── JavaScript：导航、词卡队列、搜索、拼写、自评规则
  ├── speechSynthesis：设备提供的语音合成
  └── localStorage：复习进度、每日计数、表达草稿
              ↕
       JSON 导出 / 导入
```

选择原生 HTML / CSS / JavaScript 的原因：内容规模小，交互全部发生在浏览器，不需要构建工具；单文件方便复制、备份和离线打开。词库嵌入文件中，没有 fetch、外部字体、CDN 或第三方分析脚本。

如果后续增加数千词条或多人共享，再拆分数据、样式与应用逻辑；当前不引入 React、数据库或模型 API。

### 词条数据

每个词条运行时包含：

```json
{
  "id": "job-0",
  "deck": "job",
  "term": "reconciliation",
  "pos": "n.",
  "meaning": "对账；核对账目",
  "collocation": "daily reconciliation",
  "example": "Daily reconciliation helps our team find missing payment records.",
  "translation": "每日对账帮助我们的团队发现缺失的支付记录。"
}
```

当前 ID 根据分类和词条顺序生成。维护词库时不要重排已有词条，以免错配历史进度；新增条目应追加。扩展到可编辑词库前，需要改为显式稳定 ID，并进行旧进度迁移。

### 学习记录

存储键：`wordcraft-study-v1`，结构版本：`1`。

```json
{
  "version": 1,
  "reviews": {
    "job-0": { "stage": 1, "due": 1794805200000, "count": 1 }
  },
  "days": { "2026-11-15": ["job-0"] },
  "drafts": { "0": "I would use an idempotency key." }
}
```

- `stage`：连续“记住了”所推进的阶段，0–5；不是雅思分数或真实掌握率。
- `due`：下次复习的绝对毫秒时间。
- `count`：该词累计自评次数。
- `days`：浏览器本地日历日对应的已自评词条 ID，去重后显示每日进度。
- `drafts`：三个场景分别保存文本草稿，单场景上限 20,000 字符。

本地日期跟随设备时区；不会固定成服务器时区。初始进度为零，不展示模拟学习数据。

## 5. 复习调度

这是透明的轻量阶梯规则，不是 SM-2 或 FSRS，也不预测遗忘概率。

| 自评 | 下次时间 | 阶段处理 |
| --- | --- | --- |
| 还没记住 | 当前时间 + 10 分钟 | 重置为 0 |
| 有点印象 | 当前时间 + 1 天 | 保持原阶段 |
| 记住了 | 依次间隔 1、3、7、14、30 天 | 前进一阶段，最大为 5；之后保持 30 天 |

打开某个词库时，按到期时间升序列出已到期词条，再接未学习词条。当前队列结束后显示下次复习时间，并可手动刷新队列；没有后台推送或计时器自动跳转。选择“浏览全部词汇”可提前查看，也可主动重新自评并重新安排复习。

浏览词卡、播放声音和查看答案都不计入每日完成。每次自评记录一次学习，但每日进度按词条去重。

## 6. 本地打开与数据保留

最快方式：使用浏览器打开同目录的 `index.html`，页面内容和练习不需要后台。

长期使用建议固定一个本地 HTTP 地址，以得到更一致的存储行为：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory '/Users/cliff/workspace/learn/英语/study'
```

浏览器访问 [本地学习页](http://127.0.0.1:8765/)。该服务运行在前台；停止它后，HTTP 地址不可访问，但 HTML 文件仍可直接打开。端口被占用时可换一个端口；若希望保留同一份浏览器进度，长期使用时应保持地址、主机名和端口一致。

[MDN localStorage 文档](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)说明数据按来源隔离；对直接用 `file:` 打开的文件，其行为没有统一保证。因此从文件切换到 HTTP、改变端口或换浏览器时，先导出 JSON，再在新位置导入。隐私窗口或清理站点数据也会影响持久化。读取／写入失败时页面显示提示，并允许导出内存中的进度。

[MDN SpeechSynthesis 文档](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)介绍了设备可用声音的读取和播放接口。页面优先选英语声音并以 0.85 倍语速播放；语音质量和能否离线播放取决于设备声音包或浏览器服务。页面不提供录音或发音评分，也不宣称专业词发音已由真人校对。

## 8. 验收标准

1. 三组词库均有 16 条有效记录，英文、中文、搭配、例句及来源字段完整。
2. 查看答案不改变进度；自评安排正确的下次时间，刷新后记录仍存在。
3. 同一词当天多次自评仅增加一次每日词数，到期队列优先于新词。
4. 中英文搜索、分类过滤和点击词条跳转正常；无结果时明确提示。
5. 拼写正确／错误均给出反馈，题目推进正常；场景草稿互不覆盖且可恢复。
6. JSON 备份可导出再导入；错误结构、未知词条、过大文件不会替换有效进度。
7. 桌面与窄屏正常显示，无整页横向溢出；表格可在自己的容器内横向滚动。
8. 缺少存储或语音支持时给出说明，不阻断其他学习功能。

浏览器测试结果记录在同目录的 `验收记录.md`。听力实际音色和长期学习效果仍需真实使用者验证。
