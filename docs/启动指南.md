# 启动指南

## 日常启动

本机已完成安装。在终端执行：

```sh
cd /Users/cliff/workspace/English-Learning
python3 scripts/manage.py start
```

打开 [学习页面](http://127.0.0.1:8765/)。接口文档在 [API 文档](http://127.0.0.1:8766/docs)。

前端和后端在后台运行，关闭终端后仍可使用。电脑重启后需要重新执行启动命令；本项目未配置开机自启。重复启动会提示服务已运行。

## 查看状态

```sh
cd /Users/cliff/workspace/English-Learning
python3 scripts/manage.py status
```

正常情况下前后端均显示 `running`，应用显示 `ready`。

## 重启

修改本地 `.env` 或后端代码后：

```sh
cd /Users/cliff/workspace/English-Learning
python3 scripts/manage.py restart
```

修改前端代码后，需要先重新构建，再重启：

```sh
cd /Users/cliff/workspace/English-Learning
npm --prefix frontend run build
python3 scripts/manage.py restart
```

## 停止

```sh
cd /Users/cliff/workspace/English-Learning
python3 scripts/manage.py stop
```

停止服务不会删除学习数据。

## 首次安装或重新安装依赖

仅在首次下载项目、换电脑或更新依赖后执行。需要 Python 3.11+、Node.js 22.12+ 和 npm；本机已验证 Python 3.14.4、Node.js 22.22.0。如果项目存放在其他目录，请替换下面的路径。

```sh
cd /Users/cliff/workspace/English-Learning
python3 scripts/manage.py stop
sh scripts/setup.sh
python3 scripts/manage.py start
```

安装脚本创建 Python 虚拟环境、安装锁定的依赖、构建前端并初始化数据库，不清空已有学习数据。

新电脑如需 YouTube 关键词采集，可在不存在 `.env` 时从 `.env.example` 复制并填写 `YOUTUBE_API_KEY`，随后重启。已配置的本机 `.env` 无需覆盖。字幕与本地词典的准备方法见 [字幕与查词说明](video-transcripts.md)。

## 启动异常与日志

```sh
cd /Users/cliff/workspace/English-Learning
tail -n 80 .runtime/backend.log
tail -n 80 .runtime/frontend.log
```

日志在首次启动后生成。端口 8765 或 8766 被其他程序占用时，启动脚本会报错；请先确认占用程序，脚本不会自动终止其他应用。仅一个服务运行时，可执行重启命令恢复。

## 备份学习数据

```sh
cd /Users/cliff/workspace/English-Learning
PYTHONPATH=backend .venv/bin/python -m app.cli backup
```

完整备份保存在 `backups/`，包含学习词库、复习记录、视频笔记、字幕和查词词典。默认数据库是 `data/wordcraft.sqlite3`，也可由 `.env` 中的 `WORDCRAFT_DB` 指定绝对路径。

`.env`、数据库、个人语料和备份均不提交到 Git。换电脑时，克隆代码不会带上个人学习数据，需要另行迁移数据库及本地配置。目录迁移与回退说明见 [迁移记录](migration-2026-11-15.md)。
